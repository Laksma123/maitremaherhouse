# Paket 31 Snapshot Realistis Bertahap & Prompt Ketat (Zero-Surprise) untuk Gemini Web

Seluruh **31 file gambar `.jpg` (16:9, nama bahasa Inggris `01` s/d `31`)** di folder ini dirancang khusus untuk **Gemini Web (`1 Foto + 1 Prompt`, TANPA Start & End Frame)** menggunakan dua prinsip anti-*surprise*:
1. **Kunci Gerak Kamera Ketat di Dalam Bingkai Foto (*Strict In-Frame Motion Lock*):** Setiap *prompt* membatasi kamera agar **hanya maju tipis 1–2 langkah pendek atau bernapas alami di tempat** menuju titik yang **sudah terlihat jelas di dalam foto**, serta **melarang keras kamera menoleh keluar batas kiri/kanan foto, berbelok di tikungan buta, atau menembus ambang pintu ke ruangan yang belum terlihat**.
2. **Transisi Bertahap Dekat & Logis Antar-Scene (*Step-by-Step Logical Reveal*):** Pergantian sudut pandang, pembukaan pintu, dan objek di balik dinding dilakukan lewat bidikan berurutan jarak dekat (contoh: `07` berdiri di depan pintu utama tertutup → `08` pintu utama dibuka sehingga isi ruang tengah terlihat lurus di depan → `09` melangkah masuk sedikit melewati dinding sekat sehingga dapur di balik dinding baru terlihat secara logis).

---

## Cara Pakai di Gemini Web (`gemini.google.com`)
1. Buka **Gemini Web** dan pilih mode pembuatan **Video**.
2. Unggah **1 foto saja** sesuai urutan nomor (`01_...jpg` sampai `31_...jpg`).
3. *Copy-paste* **Prompt Gemini Web** di bawah foto tersebut.
4. Saat menyusun video akhir di editor (CapCut / iMovie / Premiere), Anda dapat memakai keseluruhan klip atau mengambil **3–4 detik paling mulus** dari tiap klip dan menyambungkannya berurutan `01` → `31` (~1 menit 50 detik total dokumentasi *First-Person POV*).
