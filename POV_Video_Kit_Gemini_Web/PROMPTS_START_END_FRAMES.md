# 🎬 Panduan & Prompt Video `Start Frame + End Frame` (14 Foto = 13 Klip Berantai)

Folder ini telah dipangkas kembali ke **14 foto rekayasa AI fotorealistis (`01` s/d `14`)** dengan nama file bahasa Inggris yang rapi. Karena ke-14 foto disusun berantai (**`End Frame` klip sebelumnya menjadi `Start Frame` klip berikutnya**), Anda akan menghasilkan **13 klip video yang menyambung 100% mulus seperti satu rekaman *one-take walkthrough* tanpa kejutan sudut pandang**.

---

## Cara Pakai (`Google Labs Flow` / `Kling` / `Luma` / `Runway` — Mode Start & End Frame)
1. Buka alat pembuat video yang memiliki slot **Start Frame (First Frame)** dan **End Frame (Last Frame)** — misalnya **Google Labs Flow (`https://labs.google/fx/tools/flow` → Video → Frames)**.
2. Pilih rasio **16:9** dan durasi **8 detik** (atau 5–8 detik).
3. Untuk setiap klip di bawah (`Clip 01` s/d `Clip 13`):
   * Unggah file **`Start Frame`** ke kotak gambar awal (*First / Start Frame*).
   * Unggah file **`End Frame`** ke kotak gambar akhir (*Last / End Frame*).
   * *Copy-paste* **Prompt Start → End** di bawahnya lalu klik **Generate**.
4. Gabungkan hasil `Clip 01` → `Clip 13` secara berurutan di editor video (CapCut / iMovie / Premiere).
